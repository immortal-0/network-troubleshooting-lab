# Network-troubleshooting-lab
Diagnosed, corrected, configured, verified, and tested.


This project focuses on troubleshooting and validating a simulated
enterprise network using Cisco Packet Tracer.

I was provided with an existing network containing configuration problems. My objective
was to identify the faults, correct the configurations, and verify
successful network operation.

## Technologies and Concepts

- VLANs
- 802.1Q Trunking
- EtherChannel
- Port Security
- PVST+
- DHCP
- IPv4 Routing
- IPv6 Routing
- OSPFv2
- OSPFv3
- Default Routes
- NAT
- WAN Connectivity
- Route Path Selection
- Backup/Failover Links
- Ping and Traceroute
- Cisco IOS Troubleshooting

## Troubleshooting Tasks

I investigated and corrected issues involving:

- Incorrect VLAN membership
- Port security configuration
- EtherChannel configuration
- Trunk/native VLAN configuration
- Spanning-tree root bridge selection
- Incorrect DHCP gateway settings
- OSPF route propagation
- IPv4 and IPv6 default routes
- WAN routing path selection
- OSPF interface costs
- NAT inside/outside interfaces
- Backup WAN connectivity
